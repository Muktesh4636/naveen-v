Install on Chrome

Google only allows one-click install from the Chrome Web Store. VisaBook installs from this site in a few steps.

  1. Click Add to Chrome above — your browser downloads visa-book-extension.zip. Unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and select the unzipped visa-book-extension folder.
  4. Open USVisaScheduling.com — the toolbar icon confirms it is active.
